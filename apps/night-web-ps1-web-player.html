Night Web PS1 Web Player

Runs entirely in your browser via the open-source EmulatorJS project. Bring your own BIOS and game dumps.

1
BIOS file
The console firmware, dumped from hardware you own. One file, usually .bin.
2
Game file(s)
.bin+.cue, .pbp, .img, .m3u, .ccd, or .zip. Select every file for multi-track discs at once.
> waiting for bios and game files
Nothing is uploaded. Your BIOS and game files stay in this browser tab. Only use dumps you're legally entitled to use.

First launch downloads the PS1 core (a few MB) from the EmulatorJS CDN, so you'll need an internet connection once. If opening this file directly does nothing, some browsers block local pages from doing that — instead serve the folder with a local web server (e.g. python3 -m http.server) and open it at http://localhost:8000.
Running

Default keyboard controls are arrow keys plus Z / X / A / S. Click the gear icon inside the player to remap controls, connect a gamepad, use save states, or go fullscreen.
